# 出品メーカー v6

v5の写真文字入れ、カテゴリー別商品情報、説明文生成、共通文章設定、ホーム画面アイコンを維持し、商品情報の自動保存を追加した版です。

## 自動保存の対象
- ブランド名、右上文字、画像比率、文字サイズ、背景の濃さ
- カテゴリー、商品名、サイズ、色、状態、付属品、補足
- 各カテゴリー専用入力欄（切替前の入力も保持）
- 生成・編集したタイトルと説明文

ブラウザのlocalStorageへ入力時に自動保存します。次回、同じブラウザ・同じURLで開くと復元します。

**写真ファイルは自動保存されません。** 写真を再選択してください。端末のブラウザデータを消した場合、プライベートブラウズや別端末では復元できません。共通文章の設定は従来どおり別に保存されます。

「入力内容をクリア」で商品情報だけを消去できます。共通文章は残ります。

## GitHub Pagesへの反映
1. ZIPを解凍し、8ファイルを `mercari-ai-assistant` リポジトリ直下にアップロードしてコミット。
2. GitHub Pagesの公開更新後、ホーム画面のアプリを開き直す。
3. 商品名を入力し、一度閉じて再度開き、復元されるか確認。

スマホ実機での動作確認は未実施です。メルカリ公式アプリではありません。

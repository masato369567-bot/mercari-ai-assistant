# メルカリ出品メーカー 試作版

スマホで1枚目の写真に統一デザインの文字を入れ、商品タイトルと説明文を作る無料の静的Webアプリです。

## 機能
- 元画像・正方形1080×1080・縦長1080×1350・横長1350×1080から選んだ写真に左上ブランド名と任意の右上文字を配置
- 写真のドラッグ移動・ピンチ拡大縮小・ボタンで拡大縮小
- JPG保存・端末の共有シートに対応（カメラロールへの直接保存は不可）
- 商品情報からタイトル（最大40文字）と説明文を自動作成
- 共通文章5項目のON/OFF、編集、端末内自動保存、その他の文章
- コピー機能

## 初期設定について
「ペットは飼っていません」は事実確認が必要なので初期状態ではOFFです。事実ならONにしてください。「値下げ交渉OK」なども出品方針に応じて変更できます。

## GitHub Pages
1. ZIPを解凍して `index.html` `style.css` `app.js` `README.md` をリポジトリ直下にアップロードします。
2. Settings > Pages で `Deploy from a branch`、`main`、`/(root)` を設定します。
3. 公開サイトをスマホで開いてテストします。

## 制限
- AI画像認識はありません。商品情報は手入力です。
- 画像と入力情報はサーバーへ送信しません。設定はブラウザのlocalStorageに保存します。
- 端末のブラウザデータを消すと共通文章の設定が消えます。
- 写真が正方形にトリミングされることがあります。被写体の位置を調整してください。
- 実機での動作確認は未実施です。

## 更新点
- 古着の購入に関する共通文を追加（ON/OFF可能）。
- 「お値下げ交渉」を「値下げ交渉」に変更。旧設定は起動時に移行。
- iPhone/Androidで対応している場合、保存ボタンから共有シートを開きます。写真アプリへの保存操作は利用者が選択します。共有に非対応ならダウンロードします。
- 画面をダークネイビーとウォームベージュのデザインに刷新。

## v3 画像比率
- 初期値は「元画像の比率」。元画像を切らずに表示します（長辺最大1600px）。
- 正方形、縦長、横長も選択可能です。切り抜き位置はドラッグで調整できます。
- 文字は左上固定、右上は任意のままです。

# メルカリ出品サポート（無料試作版）

スマホ向けの静的Webアプリです。GitHub Pagesで公開できます。

## 機能
- 写真を最大10枚選択し、明るさ・コントラスト・彩度を個別に補正
- 編集写真をJPEGで保存（長辺最大1600px）
- 入力した商品情報から40文字以内のタイトルと説明文を作成
- コピー機能

## v3 の変更
- 写真から商品種類をMobileNetで分類
- 写真内の英字をTesseract.jsでOCRし、登録ブランド候補を入力
- 商品中央部から代表色を推定
- AIの推定信頼度と未確認項目を表示
- 初回解析時はモデルをインターネットから読み込みます。完全オフラインではありません。
- ブランド・型番の網羅的な特定や商品の正式名称検索はできません。

## v2 の変更
- 元画像と補正後画像を横に並べて表示
- 補正値を動かすと選択中のサムネイルも更新
- 写真からの商品名・ブランドの自動認識は未搭載。写真だけで確実に特定できない商品もあります。

## 注意
- 生成AI、商品自動認識、背景除去、価格査定、メルカリへの自動出品はありません。
- 商品の傷・汚れ・状態を誤認させる加工は避けてください。
- 入力情報と画像は端末のブラウザ内で処理し、サーバーには送信しません。
- 写真はページを閉じると消えます。編集結果は保存してください。
- 一部のスマホでは複数画像の一括ダウンロードが制限されます。その場合は1枚ずつ保存してください。

## GitHub Pagesへの設置
1. `index.html`、`style.css`、`app.js`、`README.md` をリポジトリ直下にアップロード。
2. Settings > Pages > Deploy from a branch を選択。
3. Branchを `main`、フォルダを `/(root)` にして保存。
4. 公開後にスマホで操作を確認。

外部APIや課金サービスは不要です。

# 出品メーカー v5

GitHub Pages用のスマホ向け静的Webアプリです。メルカリ公式アプリではありません。

## ファイル
- `index.html`, `style.css`, `app.js`: アプリ本体
- `manifest.webmanifest`: ホーム画面への追加用設定
- `icon-180.png`, `icon-192.png`, `icon-512.png`: ホーム画面・PWA用アイコン

## GitHubへの反映
1. ZIPを解凍します。
2. GitHubの `mercari-ai-assistant` リポジトリで `Add file` > `Upload files` を選びます。
3. ZIP内の8ファイルをすべてリポジトリ直下へアップロードし、`Commit changes` します。
4. GitHub Pagesの公開後、SafariまたはChromeでサイトを開き直します。
5. iPhone: Safariの共有メニュー > ホーム画面に追加。Android: Chromeのメニュー > ホーム画面に追加。
6. 以前のアイコンが残る場合、ホーム画面の旧ショートカットを削除して追加し直します。

## 機能
- 左上ブランド名、右上任意文字の写真への合成
- 元画像の比率、正方形、縦長、横長の選択
- 写真の移動・拡大・縮小とJPEG保存/共有
- カテゴリー別入力（靴・衣類・バッグ・家電・その他）
- 出品タイトル・説明文の自動組み立て
- 共通文章5件のON/OFF、編集、端末内保存

## 注意
- カメラロールへの無操作の直接保存はできません。共有メニューで「画像を保存」を選ぶ必要があります。
- 写真と入力内容はサーバーへ送信しません。共通文章はブラウザのlocalStorageに保存します。
- iOS/Android実機での表示・インストール動作は未確認です。
- 画像は個人用ツールのアイコンです。メルカリ公式アプリと誤認されないようにしてください。
